# WPS Office Growth Audit

**Live → https://eddieatadapty.github.io/wps-flow-rebuild/**

Five ideas to turn more WPS Office users into subscribers, each built into a clickable version of WPS Office's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show value before the account | +10–20% CR to purchase |
| 02 | Ask one question, then use the answer | +8–15% CR to purchase |
| 03 | Move “Chosen by 200M+ Users” to the decision | +5–10% CR to purchase |
| 04 | Say $3.00 a month, next to monthly | +10–15% ARPU |
| 05 | Catch the people who close the paywall | +4–8% CR to purchase |

Every price, rating and feature comes from WPS Office's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for WPS Office. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
